# SmartCart AI — Context-Aware Add-On Recommendation System
Recommendation system developed during Zomathon 2026 to predict food add-ons users are likely to accept.

## Problem Statement
Customers often miss relevant add-on items while ordering food, leading to lost revenue opportunities.

## Solution
Built a context-aware recommendation engine predicting personalized add-ons using user behavior and ordering context.

## Features
- Synthetic dataset generation
- Feature engineering
- User behavior modeling
- Top-N recommendation ranking
- Revenue impact analysis

## Models Used
- Logistic Regression
- XGBoost

## Tech Stack
Python, Pandas, NumPy, Scikit-learn, XGBoost

## Impact
Add-on acceptance:
29.6% → 60.3%
Estimated uplift:
₹3.68 Lakhs / 10,000 sessions
